# КП для rankly.links

Коммерческое предложение на 5 слайдов, формат 16:9 (1600×900 px), тёмная тема.

## Файлы

| Файл | Что это |
| --- | --- |
| `rankly-links-kp.pdf` | Готовый PDF — то, что уходит клиенту |
| `proposal.src.html` | Исходник вёрстки (правим только его) |
| `proposal.html` | Собранное превью для браузера, шрифты вшиты в base64 |
| `fonts-embedded.css` | Unbounded + Inter (latin/cyrillic) в base64 |
| `build.sh` | Пересборка превью и PDF |

## Структура

1. Обложка
2. О нас
3. Преимущества
4. Форматы размещений (услуги и цены)
5. Прайс-лист

## Пересборка

```bash
./build.sh
```

Нужны системно установленные шрифты Unbounded (400/700/800) и Inter (400/500/600/700/800) —
без них Chromium подставит фолбэк. Забрать можно с Google Fonts и положить
в `/usr/share/fonts/truetype/`, затем `fc-cache -f`.

## Стиль

Палитра: фон `#09090B`, карточки `#0E0E11` / `#131317`, границы `#1E1E24`,
акцент — cyan `#00C2FF`, текст `#FFFFFF` / `#A3A3AC` / `#75757E`.
Заголовки — Unbounded 700/800 uppercase, текст — Inter.
